# email-to-telegram

Email-аліаси, які доставляють пошту в Telegram. Створіть адресу через
Telegram-бота, вкажіть, хто може на неї писати, і читайте листи в особистому
чаті, групі або темі форуму.

[English](README.md) · Українська · [中文](README.zh-CN.md) ·
[Français](README.fr.md) · [Italiano](README.it.md)

![Демо: створення аліаса, лист, отримання в Telegram](docs/assets/demo.gif)

## Два способи користуватися

**Готовий бот.** Відкрийте [@tgemails_Bot](https://t.me/tgemails_Bot),
надішліть `/start`, потім `/newemail`. За кілька секунд адреса працює. Не
потрібні ні домен, ні сервер, ні акаунт Cloudflare. Безкоштовний тариф дає
3 аліаси і 100 доставлених листів на місяць. Якщо вашому сценарію потрібно
більше, напишіть [@yolovlad](https://t.me/yolovlad). Перш ніж покладатися на
сервіс, прочитайте
[правила використання](https://vladkarok.github.io/email-to-telegram/hosted/acceptable-use/)
і [політику конфіденційності](https://vladkarok.github.io/email-to-telegram/hosted/privacy-and-data-requests/)
(англійською).

**Власний сервер.** Код відкритий під ліцензією MIT. Cloudflare Email Routing
приймає пошту для вашого домену, невеликий Worker перевіряє аліас, а
Node-застосунок на вашому сервері доставляє лист у Telegram. Інструкція з
розгортання є англійською:
[First deployment guide](README.md#first-deployment-guide).

## Для чого він

- сповіщення від застосунків, серверів і моніторингу доступності
- повідомлення CI, деплоїв і GitHub
- листи від SaaS-сервісів, які губляться в переповненій скриньці
- автоматизації, що вміють надсилати email, наприклад потоки Power Automate
- сповіщення команди в одній Telegram-групі або темі форуму

Бот навмисно працює в один бік і ніколи не надсилає пошту. Збережені копії
листів і вкладень видаляються (на безкоштовному тарифі через 7 днів), а самі
повідомлення лишаються в історії Telegram.

## Модель довіри

Не використовуйте проєкт як сейф або канал для секретів, кодів відновлення,
паролів, медичних, юридичних чи фінансових документів та іншої конфіденційної
інформації.

Хто може бачити вашу пошту:

- оператор сервера і будь-хто з доступом до його резервних копій
- кожен, хто має доступ до Telegram-чату, куди приходять листи
- будь-хто з доступом до токена бота

Telegram тут зручний канал, а не система екстреного оповіщення.

## Команди бота

| Команда                                        | Що робить                                               |
| ---------------------------------------------- | ------------------------------------------------------- |
| `/start`                                       | Відкрити меню керування в особистому чаті               |
| `/newemail [назва]`                            | Створити аліас для поточного чату або теми              |
| `/listemail`                                   | Список ваших аліасів                                    |
| `/pauseemail <назва>` / `/resumeemail <назва>` | Призупинити або відновити аліас                         |
| `/deleteemail <назва>`                         | Видалити аліас                                          |
| `/settings <назва>`                            | Формат листів, прибирання дублікатів, режим приватності |
| `/allow add <назва> <email_або_домен>`         | Дозволити відправника                                   |
| `/allow list <назва>`                          | Показати дозволених відправників                        |
| `/usage`                                       | Використання за цей місяць і ліміти                     |
| `/plan`                                        | Поточний тариф і його ліміти                            |
| `/language`                                    | Змінити мову бота                                       |
| `/help`                                        | Довідка                                                 |
